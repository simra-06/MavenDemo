# Maven-Demo

A simple Java Maven project created to demonstrate automated web testing using Selenium WebDriver.

## Technologies Used

- Java 21
- Maven
- Selenium WebDriver
- IntelliJ IDEA
- Google Chrome
- Git & GitHub
- Jenkins

## Project Description

This project uses Selenium WebDriver to automate a web browser. 
The program opens a website, retrieves the page title and current URL, 
and displays the results in the terminal.

## Test Website

The project currently uses:

## Maven Dependency

The project uses Selenium WebDriver through Maven:

<dependency>
    <groupId>org.seleniumhq.selenium</groupId>
    <artifactId>selenium-java</artifactId>
    <version>4.46.0</version>
</dependency>

## Purpose

This project is created as part of a DevOps practical to demonstrate:

Maven project setup
Selenium automated testing
Git and GitHub
Jenkins Continuous Integration
